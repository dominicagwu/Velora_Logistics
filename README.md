# 🚚 Velora Logistics

A modern logistics and freight management web platform designed for an international logistics business.

## 🌐 Live Website

https://velorafreight.com

## 📋 About the Project

Velora Logistics is a responsive logistics website designed to provide customers with a professional way to learn about logistics services, track shipments and interact with a freight company online.

The project focuses on creating a clean, modern and user-friendly experience across desktop, tablet and mobile devices.

## ✨ Features

- Responsive modern design
- Logistics and freight service presentation
- Shipment tracking concept
- Customer account/dashboard concept
- Business information pages
- Contact and customer support sections
- Mobile-friendly navigation
- Modern user interface
- Backend/database integration
- Production deployment

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Supabase
- Vite
- Git & GitHub
- Vercel

## 📱 Responsive Design

The platform is designed to work across:

- 📱 Mobile devices
- 💻 Desktop computers
- 📟 Tablets

## 🎯 Project Goal

The goal of Velora Logistics is to demonstrate how modern web technologies can be used to create a professional digital platform for an international logistics business.
